## 2. MỤC TIÊU DỰ ÁN

Xây dựng hệ thống quản lý bán hàng gồm 3 thành phần chính:

### A. Flutter Mobile Application

Ứng dụng dành cho:

- Chủ cửa hàng.
- Quản lý.
- Nhân viên bán hàng.
- Nhân viên kho.

Hỗ trợ Android và iOS.

### B. CMS Web Administration

Một trang quản trị web hoàn chỉnh tương tự KiotViet.

CMS được sử dụng để:

- Quản lý toàn bộ cửa hàng.
- Quản lý sản phẩm.
- Quản lý đơn hàng.
- Quản lý khách hàng.
- Quản lý nhân viên.
- Quản lý kho hàng.
- Quản lý doanh thu.
- Quản lý báo cáo.
- Quản lý cấu hình hệ thống.

### C. Backend Server

Server chạy trực tiếp trên máy tính cá nhân thông qua Docker.

Yêu cầu:

- Backend chạy trong Docker Container.
- Database chạy trong Docker Container.
- CMS chạy trong Docker Container.
- Redis chạy trong Docker Container.
- MinIO chạy trong Docker Container.
- Ngrok expose API ra Internet.
- Flutter App và CMS có thể kết nối đến server thông qua URL công khai.

Toàn bộ hệ thống có thể khởi động bằng Docker Compose.

## 9. DOCKER & DEVOPS

Tạo cấu trúc Docker hoàn chỉnh.

Các container:

- backend
- cms
- postgres
- redis
- minio
- ngrok

Tạo:

- Dockerfile cho Backend.
- Dockerfile cho CMS.
- Docker Compose.
- Environment Configuration.
- Database Migration.
- Seed Data.
- Health Check.
- Persistent Volumes.
- Logging.

Tạo các script:

./scripts/start.sh
./scripts/stop.sh
./scripts/restart.sh
./scripts/logs.sh
./scripts/backup.sh
./scripts/restore.sh

Có thể chạy toàn bộ hệ thống bằng:

docker compose up -d --build

Không hardcode API URL trong source code.

Sử dụng biến môi trường để cấu hình:

API_BASE_URL
CMS_BASE_URL
DATABASE_URL
REDIS_URL
MINIO_ENDPOINT
JWT_SECRET
NGROK_AUTHTOKEN

Ngrok phải expose Backend API qua HTTPS.

Có cơ chế cập nhật API URL khi ngrok thay đổi địa chỉ.

Không public trực tiếp PostgreSQL, Redis hoặc MinIO ra Internet.

## 10. SECURITY REQUIREMENTS

- Hash password bằng Argon2 hoặc bcrypt.
- JWT Access Token và Refresh Token.
- RBAC.
- Tenant isolation.
- Input validation.
- Rate limiting.
- CORS.
- Helmet.
- SQL Injection protection.
- XSS protection.
- CSRF protection khi phù hợp với cơ chế xác thực CMS.
- Không lưu secret trong Git.
- Không expose database ra Internet.
- Kiểm tra quyền truy cập ở Backend.
- Audit log các thao tác quan trọng.

Đặc biệt: Ngrok chỉ là tunnel để truy cập server, không phải lớp bảo mật. Phải triển khai authentication và authorization đầy đủ.
